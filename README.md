PARADOX 3307 is a **super simple** encryption tool. No installation,
no Python, no dependencies — just download the EXE, double-click it,
and pick a number from the menu. That's it.

- 🔒 Strong encryption: **ChaCha20** (same cipher used in TLS/Signal)
- 🛡️ Password hardening: **scrypt** key derivation
- ✅ Tamper protection: **HMAC-SHA256** (any change to the file = detected)
- 🔢 Hashes: SHA-256, SHA-512, SHA3, BLAKE2
- 🎲 Secure password & key generator
- 🧹 Secure file destruction

**100% built with Python's standard library — nothing to install.**
